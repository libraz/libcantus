# ユースケース

各ガイドは、アプリケーションがすでに持っているデータから始まり、その結果をどう使うかを示します。各領域のページと生成された API リファレンスを補うものです。

解析と検査:

- [DAW ワークフロー](daw-workflow.md): トラックから和声を推定し、それに対してベースラインを生成します。
- [楽曲の解析](piece-analysis.md): 調区間、終止、縮約、フレーズ、セクション、モチーフを求めます。
- [転調レポート](modulation-report.md): 調の変化を、ピボットと信頼度とともに提示します。
- [和声課題チェッカー](harmony-exercise-checker.md): 和声課題と種目対位法の違反を報告します。

素材の生成:

- [生成アレンジ](generative-arrangement.md): 再現可能な進行、パート、ドラムを作り、演奏可能性を検査します。
- [コード譜の取り込み](chord-chart-import.md): 入力されたコード記号をタイムライン、ボイシング、ベースラインにします。
- [パートの準備](part-preparation.md): パートを楽器に合わせ、奏者が読む音高で書き出します。

すべての例は MIDI ピッチ番号と4分音符を単位とする拍を使います。ファイル入出力、MIDI の解析、記譜、音声解析、再生はホストアプリケーションの担当です。その境界での変換は[相互運用](../interoperability.md)を参照してください。

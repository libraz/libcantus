# 入門

入門は、他のガイドが前提としている音楽の考え方を、TypeScript は読めても音楽を学んだことはない読者に向けて説明します。各ページは1つの概念を平易な言葉で説明し、それがこの API で何を決めているのかを述べ、実行できる短い例を示したうえで、関数を網羅する各分野のガイドへ引き継ぎます。

音楽理論の講座の代わりにはなりません。このライブラリがモデル化しているものを扱ってそこで止まります。演奏実践や管弦楽法、実際に耳で聞き分ける話は含みません。音楽の約束事が本来任意である箇所では、存在しない理由を作らずに、任意であるとそのまま書いています。

## 6つのページのつながり

順に積み上がる構成で、各ページは前のページが定義した用語を使います。

1. [ピッチと音程](pitch-and-intervals.md) — 1つの音と、2つの音のあいだの距離。他のすべてはこの用語で述べられます。
2. [音階と調](scales-and-keys.md) — 楽節が使う音の材料と、それを名付ける調。
3. [和音](chords.md) — 同時に鳴る音と、その識別と命名。
4. [和声](harmony.md) — 調に対して読んだ和音。ローマ数字、機能、終止形。
5. [声部](voices.md) — 同じ和音を同時に進む複数の旋律線として配置したものと、その進み方を律する規則。
6. [リズムと拍子](rhythm-and-meter.md) — 音が何であるかとは独立に、いつ鳴るか。

最初の2つは次の3つの前提になります。リズムと拍子は他の5つから独立していて、どの時点で読んでもかまいません。

どのページも構成は同じです。概念を平易な言葉で述べ、それが API に強いている判断を示し、実行できる例を並べ、さらに進む先のガイドへリンクします。用語はページ内で最初に出たところで説明するので、前のページを読まずにそのページだけを開いても読み進められます。

## 各概念が決めていること

中央の列は、プログラマがその概念を必要とする理由そのものです。知らないことが語彙の欠落ではなく、誤った呼び出しになって現れる箇所を挙げています。

| 概念 | この API で決めていること | ページ |
|---|---|---|
| ピッチ・ピッチクラス・綴り | 値が MIDI 番号か、ピッチクラスか、綴られた `Note` か。そして多くの関数が、それ以外には必要としない調を要求する理由 | [ピッチと音程](pitch-and-intervals.md) |
| 音程 | どちらも6半音の `A4` と `d5` が別の値である理由と、移高の結果がどう綴られるか | [ピッチと音程](pitch-and-intervals.md) |
| 音階・旋法・調 | `KeyScale`・`ResolvedKey`・`Key` がそれぞれ何を持つか。そして、名前のある音階のうちどれがローマ数字の読みに耐えるか | [音階と調](scales-and-keys.md) |
| 和音・種類・転回 | `Chord` が根音・種類・音程・バスをどう分けて持つか。そして和音検出が何と何を選び分けているか | [和音](chords.md) |
| ローマ数字・機能・終止形 | 和音の分析に調の文脈が要る理由と、終止形の報告が何を主張しているか | [和声](harmony.md) |
| ボイシング・声部進行 | 和音が4つのピッチになる過程と、`checkPartWriting` が何を検査しているか | [声部](voices.md) |
| 拍・小節・拍子・テンポ | 時間の値がすべて4分音符を1拍とすることと、拍を秒にするのはテンポだけであること | [リズムと拍子](rhythm-and-meter.md) |

## 次に読むページ

まず動く例から入るなら[はじめに](../getting-started.md)へ進み、知らない用語が出たところで入門に戻ってください。これらの部品を組み合わせた一連の流れ — チャートの取り込み、曲の分析、パート譜の準備、和声課題の添削など — は[ユースケース](../use-cases/index.md)にあります。

各分野のガイドは、リンク先の入門ページを前提としていて、その内容を繰り返しません。ガイドを読んでいて説明なしに使われている用語に出会ったら、その用語を扱う入門ページを開いてください。

入門の各ページは、末尾でそれぞれの分野のガイドへリンクしています。全体は次のとおりです。[音高と記譜](../pitch-and-notation.md)、[音律と周波数](../tuning-and-frequency.md)、[スケールとモード](../scales-and-modes.md)、[調関係と転調](../key-relations-and-modulation.md)、[和声](../harmony.md)、[ボイシング](../voicing.md)、[対位法と声部書法](../counterpoint-and-part-writing.md)、[時間と編曲](../time-and-arrangement.md)、[リズムとグルーヴ](../rhythm-and-groove.md)、[解析](../analysis.md)、[生成](../generation.md)。[用語集](../glossary.md)は用語そのものを定義し、[API リファレンス](../api-reference.md)はすべてのエクスポートを一覧します。

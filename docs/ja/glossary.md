# 用語集

このライブラリでの用法をまとめます。一般に複数の意味を持つ音楽用語については、API が実装しているほうの意味を示します。

## データモデル

**NoteEvent** — 鳴っている音。`pitch`（MIDI 番号）、`startBeat`、`durationBeat`、および任意の `velocity` と `articulation` を持ちます。時間の単位は全体を通して4分音符1拍です。

**ピッチクラス** — ピッチを12で割った余り。C4 と C5 はどちらもピッチクラス0です。ピッチ層より上の解析はピッチクラスで動作します。

**綴られた音** — 音名の文字、変化記号、任意のオクターブ。`parseNote('Bb3')` は綴られた音で、MIDI 58 はそうではありません。オクターブを持たない綴られた音は、ピッチクラスを持ちますが MIDI 番号を持ちません。

**KeyScale** — ルートのピッチクラスと12ビットの `modeMask12` の組。ビット n が立っていれば、ルートの n 半音上の音が含まれます。調、旋法、その他あらゆるスケールの表現です。

**SpelledKey** — `KeyScale` と、音名の基準となる綴られた主音の組。変ニ長調と嬰ハ長調は同じ `KeyScale` で、異なる `SpelledKey` です。

**ChordSpec** — 構造としてのコード。基本の性質に加えて、7th、変化音、付加音、省略音、任意のベースを持ちます。固定の一覧から選ぶ名前ではありません。

**ChordSegment** — 開始拍と終了拍、およびその読みの信頼度を持つコード。コードタイムラインを構成する単位です。

**MotifCell** — 配置される前の、音高とリズムとしてのモチーフ素材。`motifToNoteEvents` がセルをノートイベントに変換します。

**GenerationContext** — 1曲の中ですべてのジェネレータが共有する、シード、つまみ、テンポ、楽器、vocabulary。数値だけを渡すと `{ seed }` の略記になります。

## 音高と音程

**綴られた音程** — 全音階上の度数と半音数の両方を持つ音程。増4度と減5度は同じ6半音ですが、別のものとして保たれます。

**異名同音** — 同じ響きの音や調に対する2通りの綴り。F# と Gb、嬰ハ短調と変ニ短調など。

**セント** — 平均律の半音の100分の1で、対数尺の単位。音律のずれを測る単位です。

**EDO** — オクターブの等分数。12-EDO が標準の音律で、`edo(19)` は19等分平均律を作ります。12-EDO 以外では、ステップ番号は MIDI 番号ではありません。

## 和声

**全音階的（ダイアトニック）** — 変化を加えずに現在の調に属すること。`isDiatonic` はコード全体を判定します。

**ローマ数字** — 調に対する音度でコードを表す記法。大文字・小文字と接尾辞が性質を表します。`chordToRoman` が生成し、`romanToChord` が読み戻します。

**副属和音** — 主音以外の度数を一時的に主音として扱う属和音。`V7/V` のように書きます。調は変わりません。`chordToRoman` がこの形で書くのは `applied: true` のときだけです。

**借用和音** — 主音を変えずに同主調から取ったコード。ハ長調における F マイナーなど。`borrowedSource` が借用元を返します。

**モーダルインターチェンジ** — 借用を一般的な手法として捉えたもの。`modalInterchangePalette` は、その調で利用できる全体を返します。

**一時的転調（トニサイゼーション）** — 調を離れずに、ある度数を一時的な主音として扱うこと。これに対して転調は、調性の中心が持続的に移ることを指します。

**ピボットコード** — 新旧どちらの調でも全音階に属するコード。転調の説明に使います。

**終止（カデンツ）** — 和声的な終止形。`detectCadence` が種類を返し、ボイシングからソプラノが特定できる場合は正格終止を完全・不完全に分類します。

**和声機能** — コードがトニック・サブドミナント・ドミナントのどれとして働くか。`functionOf` が返します。意味を持つのは `supportsFunctionalHarmony` が真の場合だけです。

**増六の和音** — 下方中音上に作られるイタリア・フランス・ドイツの和音。ローマ数字で表せないため、`It6`、`Fr6`、`Ger6` として出力されます。

**ナポリの和音** — 下方第2度上の長三和音。第1転回形では `bII6`、`neapolitan: true` のときは `N6` と書かれます。

**ネガティブハーモニー** — 調の軸に対するコードの反転。結果がちょうど1つに定まる変換であり、提案ではありません。

## スケール

**旋法（モード）** — 別の度数を主音として取り直したスケールの回転形。ドリアンとイオニアンはピッチクラス集合を共有し、主音が異なります。

**アボイドノート** — コード構成音の半音上に位置する非コード構成音のスケール音。和音に重ねると濁ります。

**テンション** — 色としてコードに加えられる非コード構成音のスケール音。

**コードスケール** — コードに適合するよう選ばれたスケール。`chordScales` が候補を順位づけ、`scalesForChanges` は連続性を保った経路全体を選びます。

**スケール体系** — スケールがどの分析的伝統に属するか。`common-practice`、`modal`、`non-functional` の3つです。機能和声のラベルが当てはまるのは前2つだけです。

## ボイシングと対位法

**ボイシング** — 声部ごとに1つのピッチとして実現されたコード。低い順に並び、添字0が最低声部です。

**声部進行（ボイスリーディング）** — コード間で各声部がどう動くか。`voiceLeadingCost` はその総移動量（半音）です。

**ドロップボイシング** — 密集配置から上声部を1オクターブ下げた配置。ドロップ2は上から2番目、ドロップ3は上から3番目を下げます。

**シェルボイシング** — ルート・3度・7度。コードを識別する音だけを残した形です。

**ルートレスボイシング** — 3度・5度・7度とテンション。ルートはベースに任せます。

**並行完全** — 2声が同じ方向へ動きながら完全5度・完全8度・ユニゾンを保つこと。`createsParallelPerfect` が1つの進行を判定します。

**隠伏完全（直行）** — 外声が跳躍しながら同じ方向で完全音程に達すること。並行より軽く扱われ、別の種類として報告されます。

**対斜** — 和音の変わり目で、同じ音の本位形と変化形が別々の声部に現れること。綴られた音からのみ判定できます。

**種目対位法** — 第1種から第5種までの段階的な課題体系で、種目ごとに許される不協和が異なります。`checkSpecies` が採点します。

**定旋律（カントゥス・フィルムス）** — 種目対位法で与えられる側の声部。1小節1音です。

**通奏低音（数字付き低音）** — 音程を数字で示した低音声部。`realizeFiguredBass` は音程を調から取るため、同じ数字でも度数が違えば綴りが変わります。

## リズムと形式

**拍子マップ** — `{ startBeat, ts }` の変化の配列。単一の `TimeSignature` は要素1つのマップの略記です。

**拍節強度** — 拍の位置の強さ。0（拍から外れた位置）から3（強拍）まで。発音位置の配置とアクセント整形の基礎になります。

**ハイパーメーター** — 小節より上の階層の拍節構造。小節が2つ組・4つ組でまとまる感覚を指します。

**フレーズ** — 終止、休符、反復、ハイパーメーター上の位置から提案される区間。観測可能な信号からの提案であって、意図についての主張ではありません。

**和声リズム** — 和声が変わる頻度（拍単位）。コードタイムラインやハーモナイズが量子化される格子を決めます。

**グルーヴテンプレート** — 演奏から取り出した1小節分のタイミングとベロシティのずれの格子。他の素材にも適用できます。

**ヒューマナイズ** — 量子化されたイベントを格子からずらし、拍節上の位置に応じてベロシティを整えること。

## 生成

**シード** — ジェネレータの出力を確定させる数値。1つのプロジェクトシードから各パートの乱数が導かれます。

**位置指定の抽選** — 呼び出し順ではなく位置で指定される乱数値。パラメータを1つ変えても、それ以降が引き直しになりません。

**complexity** — `rhythmic`・`harmonic`・`ornament` の 0..1 のつまみ。上げると素材が増え、すでに鳴っているものは動きません。

**difficulty** — 演奏の難しさの上限（1から5）。強度を上げるのではなく候補を削り、作用するのはタイミングの層だけです。

**アルゴリズムバージョン** — 再現性の保証を担う、パッケージバージョンとは別の番号。バージョンを固定すれば、それを受け付けるどのビルドでも同じ入力から同じ出力が得られます。

**vocabulary** — 呼び出し側が持ち込む、組み込み以外の figures。ジェネレータが利用できる素材を追加します。

## 楽器

**楽器プロファイル** — 楽器をその実体で記述したもの。弦楽器はチューニングとフレット数、ドラムキットは手足と可達範囲です。

**演奏可能性の層** — 障害の種類。1はその音が存在しない、2は配置として成立しない、3は時間が足りないことを表します。

**移調楽器** — 記譜音と実音が異なる楽器。`toSoundingPitch` と `toWrittenPitch` が綴りを保ったまま変換します。

**実音** — 実際に鳴る音高。解析はこの音高で動作します。
